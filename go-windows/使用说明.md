# VNT Go 客户端

用 Go + walk 重写的 Windows 桌面客户端，界面与功能对齐 C# 版本。

## 文件

| 文件 | 说明 |
|---|---|
| **VntGo.exe** | 客户端主程序（6 MB，单文件，无需运行时） |
| vnt-cli.exe | VNT 核心 v1.2.16 |
| vnt.ico | 图标 |
| build.bat | 重新编译脚本 |
| vnt.manifest | 应用清单（Common Controls v6 + DPI 感知 + 管理员权限） |
| src 文件 | `main.go` `config.go` `vnt.go` `autostart.go` |

## 快速开始

**右键 `VntGo.exe` → 以管理员身份运行**

（清单已声明 `requireAdministrator`，正常情况下会直接弹出 UAC 提示）

1. 打开「配置」页，填写 Token 和服务器地址
2. 点「保存配置」
3. 回到「状态」页点「启动组网」

## 界面说明

### 状态页

| 显示项 | 说明 |
|---|---|
| 连接状态 | 绿点「已连接」/ 灰「未运行」 |
| 虚拟 IP | 服务端分配的地址 |
| NAT 类型 | Cone（可 P2P）/ Symmetric（通常只能中继） |
| 服务器 | 当前中继服务器地址 |
| 公网 IP | 本地出口公网地址 |

**在线设备表格**：设备名、虚拟 IP、状态、连接方式、延迟。每 3 秒刷新。

连接方式：

| 显示 | 含义 |
|---|---|
| P2P 直连 | 点对点，最快 |
| 节点中继 | 经其他节点转发 |
| 服务器中继 | 经服务器转发 |

### 配置页

| 配置项 | 必填 | 说明 |
|---|---|---|
| Token | ✅ | 与服务端 `--white-token` 一致 |
| 服务器地址 | ✅ | 如 `www.example.com:8004` |
| 设备名称 | | 其他设备看到的名字 |
| 加密密码 | | 需与其他设备一致 |
| 加密模式 | | 默认 `aes_gcm` |
| MTU | | 默认 1400 |
| 虚拟 IP | | 留空由服务端分配；指定后不可重复 |
| 网络类型 | | 专用（允许被访问）/ 公用（隔离） |
| STUN 服务器 | | **留空无法 P2P** |
| 入栈网段 | | `192.168.2.0/24,10.26.0.3` |
| 出栈允许网段 | | 允许他人访问的本机网段 |
| 校验服务端指纹 | | 增强安全性 |
| 启用 LZ4 压缩 | | 减少可压缩流量 |
| 开机自动启动 | | 写入注册表，开机后台连接 |

### 运行日志

实时显示 vnt-cli 的完整输出，支持清空和复制。

## 托盘运行

点击关闭按钮 **不退出**，隐藏到托盘继续运行。

| 托盘操作 | 效果 |
|---|---|
| 左键单击 | 显示主窗口 |
| 右键 → 显示主窗口 | 同上 |
| 右键 → 启动组网 / 停止组网 | 直接控制 |
| 右键 → 退出 | **真正退出** |

托盘悬停显示：`VNT | 在线 6 | 直连 5`

## 配置文件

位置：`%APPDATA%\VntGoClient\config.ini`

```ini
token=xieyuhua
server=www.jiaoyuhua.cn:8004
device_name=MyPC
cipher_model=aes_gcm
mtu=1400
virtual_ip=
stun=stun.l.google.com:19302,stun.qq.com:3478
in_routes=
out_routes=
finger=0
compress=0
auto_start=0
network_category=Private
```

可直接编辑，程序启动时读取。

## 网络类型

Windows 会给每块网卡分配网络类别。VNT 网卡默认是**公用**，会阻止入站连接。

程序在组网启动 6 秒后自动应用配置的类别（需要管理员权限）。结果记录在运行日志里。

手动查看：

```powershell
Get-NetConnectionProfile | Where-Object { $_.InterfaceAlias -like 'vnt-tun*' }
```

## 常见问题

**启动后提示权限不足**

必须以管理员身份运行，创建虚拟网卡需要提权。

**提示"对象已存在"**

上次异常退出残留网卡：

```powershell
Get-NetAdapter -Name 'vnt-tun*' | Disable-NetAdapter -Confirm:$false
```

**界面第一次打开时控件显示异常（如 TTM_ADDTOOL 错误）**

`rsrc.syso` 未正确嵌入。用 `build.bat` 重新编译，它会先生成资源文件。**必须用 `go build .`（包模式）**，显式列 `.go` 文件会忽略 `.syso`。

**P2P 一直显示中继**

1. 确认 STUN 已配置
2. 查看 NAT 类型：`Symmetric` 表示对称 NAT，通常无法直连
3. 移动网络/运营商级 NAT 环境基本只能中继

## 重新编译

```batch
build.bat
```

或手动：

```batch
go install github.com/akavel/rsrc@latest
rsrc -manifest vnt.manifest -ico vnt.ico -o rsrc.syso
go build -ldflags="-H windowsgui -s -w" -o VntGo.exe .
```

## 与 C# 版的差异

| 项 | C# 版 | Go 版 |
|---|---|---|
| 体积 | 34 KB + 需 .NET Framework | 6 MB，单文件 |
| 运行时依赖 | .NET Framework 4.x | 无 |
| 界面技术 | WinForms | walk（Win32 封装） |
| 功能 | 完整 | 完整 |
| 配置文件 | `%APPDATA%\VntClient` | `%APPDATA%\VntGoClient` |

两个版本可以并存，配置互不影响，但**不要同时用同一 Token 启动**。
